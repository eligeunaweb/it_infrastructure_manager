# IT Infrastructure Manager

IT Infrastructure Manager is an Odoo Community module for managing customer IT infrastructure from a single place.

It helps organize servers, network interfaces, DNS zones and DNS records, keeping infrastructure information linked to the corresponding customer.

## Features

- Manage servers by customer
- Track network interfaces and IP-related information
- Manage DNS zones and DNS records
- Link infrastructure records to Odoo contacts
- Use chatter and activity features through Odoo Mail
- Dedicated menus and views for infrastructure management

## Supported Odoo versions

This repository provides dedicated branches for:

- Odoo 15: `15.0`
- Odoo 16: `16.0`
- Odoo 17: `17.0`
- Odoo 18: `18.0`
- Odoo 19: `19.0`

Use the branch that matches your Odoo version.

## Installation

1. Download or clone the branch corresponding to your Odoo version.
2. Copy the `euw_it_infrastructure` folder into your Odoo addons path.
3. Restart Odoo.
4. Update the Apps list.
5. Search for **IT Infrastructure Manager** and install it.
