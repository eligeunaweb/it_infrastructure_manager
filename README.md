# IT Infrastructure Manager for Odoo Community

Multi-version IT infrastructure management module for **Odoo Community 15, 16, 17, 18 and 19**, created by Álvaro Martínez.

IT Infrastructure Manager centralizes customer servers, network interfaces and DNS infrastructure inside Odoo, so technical information can stay linked to the corresponding customer instead of being scattered across external notes or spreadsheets.

## Highlights

- Manage servers and associate them with customers
- Manage network interfaces and infrastructure information
- Manage DNS zones and DNS records
- Link IT infrastructure to Odoo contacts
- Dedicated server, DNS and zone views
- Integrated chatter and activities through Odoo Mail
- Access control and security rules
- Dedicated IT infrastructure menus inside Odoo
- Available for Odoo Community 15, 16, 17, 18 and 19

## What is it for?

The module is designed for companies, IT departments, system administrators and service providers that need to keep customer infrastructure documented directly in Odoo.

It provides a structured place to maintain server and DNS information while keeping the relationship with each customer visible from the same business system.

## Main areas

### Servers

Maintain server records and organize infrastructure by customer.

### Network interfaces

Keep network interface information associated with the corresponding infrastructure records.

### DNS infrastructure

Manage DNS zones and DNS records from dedicated Odoo views.

### Customer integration

Infrastructure information is connected with Odoo Contacts, making it easier to identify which servers and DNS resources belong to each customer.

## Installation

1. Download or clone the branch corresponding to your Odoo version.
2. Copy `euw_it_infrastructure` into your Odoo addons path.
3. Restart Odoo.
4. Update the Apps list.
5. Search for **IT Infrastructure Manager**.
6. Install the module.
